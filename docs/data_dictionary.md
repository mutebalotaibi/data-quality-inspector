# قاموس بيانات العملاء

| الحقل | الوصف | إلزامي | مثال قاعدة جودة |
|---|---|---:|---|
| `customer_id` | المعرّف الداخلي الفريد للعميل | نعم | يبدأ بـ `CUST-` ولا يتكرر |
| `full_name` | الاسم الكامل | نعم | ليس فارغًا ويطابق المرجع عند توفره |
| `email` | البريد الإلكتروني | نعم | صيغة بريد صحيحة وغير مكرر |
| `mobile_number` | رقم الجوال السعودي | نعم | 10 أرقام ويبدأ بـ `05` |
| `national_id` | رقم الهوية (بيانات تدريبية فقط) | نعم | 10 أرقام ويبدأ بـ `1` أو `2` وغير مكرر |
| `city` | مدينة إقامة العميل | نعم | ضمن قائمة المدن المرجعية |
| `date_of_birth` | تاريخ الميلاد | نعم | تاريخ صالح ويسبق التسجيل |
| `registration_date` | تاريخ التسجيل | نعم | تاريخ صالح |
| `last_updated_at` | آخر تحديث للسجل | نعم | ضمن حد التحديث الزمني المتفق عليه |
| `customer_status` | حالة العميل | نعم | نشط أو غير نشط أو معلق |

> الأرقام والأسماء في بيانات التدريب مولّدة اصطناعيًا ولا تمثل أشخاصًا حقيقيين.
