# مشروع فحص جودة بيانات العملاء

هذه هي المرحلة الأولى من المشروع: إنشاء بيانات عملاء تجريبية آمنة للاستخدام في العرض والتدريب. لا تحتوي الملفات على بيانات أشخاص حقيقيين.

## تشغيل المشروع محليًا أو في Google Colab

يتطلب Python 3.10 أو أحدث، ولا يحتاج أي مكتبات خارجية:

```powershell
python scripts/generate_customer_data.py
python -m unittest discover -s tests -v
```

### استخدام Google Colab

بعد رفع المشروع إلى GitHub، افتح الدفتر
`notebooks/01_generate_and_validate_customer_data.ipynb` في Google Colab. ضع رابط
مستودعك في أول خلية برمجية، أزل علامة التعليق من سطري `git clone` و`%cd`، ثم شغّل
الخلايا بالترتيب. بهذه الطريقة يظل كود المشروع وبيانات التدريب موثقين في GitHub،
بينما يستخدم Colab للتنفيذ والعرض.

ينشئ الأمر ملفين تحت `data/`:

- `customers_raw.csv`: بيانات المصدر وفيها مشكلات جودة متعمدة.
- `customers_clean_reference.csv`: نسخة مرجعية سليمة للمقارنة أثناء الاختبار.

تشرح `docs/intentional_quality_issues.md` المشكلات المضمّنة. ستستخدم المرحلة القادمة الملف الخام لتشغيل قواعد الأبعاد الستة وإصدار التقرير.
